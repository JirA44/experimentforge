# Contribuer à ExperimentForge

Installez `python -m pip install -e ".[dev]"`, créez une branche, puis exécutez `python -m pytest -q` et `python -m compileall -q apps packages`.

Les évolutions conservent l'historique, incrémentent la version et mettent à jour OpenAPI. Les observations restent brutes et append-only ; effets, intervalles, diagnostics et qualifications sont calculés par le serveur, jamais acceptés du client.
